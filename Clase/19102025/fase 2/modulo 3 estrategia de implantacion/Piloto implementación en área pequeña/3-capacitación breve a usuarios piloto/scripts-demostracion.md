## 🚨 Problemas Comunes y Soluciones

### Problemas Técnicos Frecuentes
**Error de login:**
- Verificar credenciales exactas
- Comprobar conexión a internet
- Refrescar página

**Carga lenta de imágenes:**
- Usar imágenes de menor tamaño (max 2MB)
- Verificar conexión de red
- Intentar uno por uno

**Chat no actualiza:**
- Refrescar página
- Verificar que el backend esté funcionando
- Comprobar WebSocket conexión

### Problemas de Usabilidad
**Usuario confundido con navegación:**
- Mostrar nuevamente el menú principal
- Usar breadcrumbs para ubicación
- Regresar al dashboard para reorientarse

**No encuentra funcionalidad:**
- Revisar permisos del rol
- Verificar que la funcionalidad esté habilitada
- Consultar manual rápido
