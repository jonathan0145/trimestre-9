## 🎯 Objetivos del Plan de Comunicación

### 📢 Objetivo Principal
**Mantener la confianza de todos los stakeholders** mediante comunicación **transparente, oportuna y consistente** durante cualquier crisis relacionada con el despliegue Big Bang de InmoTech.

### 🎖️ Objetivos Específicos
1. **Información inmediata** a usuarios afectados (<5 min)
2. **Updates regulares** cada 15-30 minutos según severidad
3. **Transparencia** sobre problemas y tiempo estimado de resolución
4. **Coordinación** entre equipos internos y comunicación externa
5. **Preservación de reputación** de marca e imagen corporativa

---

## 📊 Clasificación de Severidad de Crisis

### 🔴 NIVEL 1: CRISIS CRÍTICA
**Impacto:** Sistema completamente inoperante  
**Usuarios afectados:** 100%  
**Tiempo de comunicación:** Inmediato (<5 min)  

**Características:**
- Sistema down completamente
- Pérdida de datos posible
- Impacto financiero significativo
- Medios de comunicación pueden involucrarse

### 🟡 NIVEL 2: CRISIS SEVERA  
**Impacto:** Funcionalidad limitada significativamente  
**Usuarios afectados:** >50%  
**Tiempo de comunicación:** <15 min  

**Características:**
- Módulos principales no funcionan
- Degradación severa de performance
- Usuarios no pueden realizar tareas críticas
- Impacto en operaciones comerciales

### 🟢 NIVEL 3: CRISIS MODERADA
**Impacto:** Problemas específicos o degradación menor  
**Usuarios afectados:** <50%  
**Tiempo de comunicación:** <30 min  

**Características:**
- Funcionalidades específicas afectadas
- Performance reducida pero sistema usable
- Workarounds disponibles
- Impacto mínimo en operaciones críticas

## 📊 Scripts Automatizados de Comunicación

### 🤖 Script de Notificación Automática

```bash
#!/bin/bash
# auto_crisis_notification.sh
# Triggered by monitoring systems

SEVERITY=$1  # critical, severe, moderate
ISSUE_DESCRIPTION=$2
ESTIMATED_RESOLUTION=$3

# Log the crisis
echo "$(date): Crisis detected - $SEVERITY - $ISSUE_DESCRIPTION" >> /var/log/crisis.log

# Send Slack notification
curl -X POST "https://hooks.slack.com/services/YOUR_WEBHOOK" \
     -H "Content-Type: application/json" \
     -d "{
       \"channel\": \"#crisis-inmotech\",
       \"text\": \"🚨 CRISIS ALERT - $SEVERITY\",
       \"attachments\": [{
         \"color\": \"danger\",
         \"fields\": [{
           \"title\": \"Issue\",
           \"value\": \"$ISSUE_DESCRIPTION\",
           \"short\": true
         }, {
           \"title\": \"ETA\", 
           \"value\": \"$ESTIMATED_RESOLUTION\",
           \"short\": true
         }]
       }]
     }"

# Update status page
curl -X POST "https://api.statuspage.io/v1/incidents" \
     -H "Authorization: OAuth YOUR_TOKEN" \
     -d "incident[name]=$ISSUE_DESCRIPTION&incident[status]=investigating"

# Send initial email to users
python3 /scripts/send_crisis_email.py "$SEVERITY" "$ISSUE_DESCRIPTION" "$ESTIMATED_RESOLUTION"

# Alert crisis manager
echo "Crisis: $ISSUE_DESCRIPTION. ETA: $ESTIMATED_RESOLUTION" | mail -s "🚨 InmoTech Crisis Alert" crisis-manager@inmotech.com
```

### 📧 Script de Email Masivo

```python
# send_crisis_email.py
import sys
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

def send_crisis_email(severity, description, eta):
    # Configuration
    smtp_server = "smtp.inmotech.com"
    port = 587
    sender_email = "alerts@inmotech.com"
    
    # Recipients based on severity
    if severity == "critical":
        recipients = ["all-users@inmotech.com", "partners@inmotech.com", "stakeholders@inmotech.com"]
    elif severity == "severe":
        recipients = ["all-users@inmotech.com", "partners@inmotech.com"]
    else:
        recipients = ["all-users@inmotech.com"]
    
    # Load template
    with open(f"/templates/crisis_email_{severity}.html", "r") as f:
        template = f.read()
    
    # Replace placeholders
    email_content = template.replace("{{DESCRIPTION}}", description)
    email_content = email_content.replace("{{ETA}}", eta)
    email_content = email_content.replace("{{TIMESTAMP}}", datetime.now().strftime("%Y-%m-%d %H:%M:%S"))
    
    # Send emails
    for recipient in recipients:
        msg = MIMEMultipart()
        msg['From'] = sender_email
        msg['To'] = recipient
        msg['Subject'] = f"🚨 InmoTech: {description}"
        
        msg.attach(MIMEText(email_content, 'html'))
        
        try:
            server = smtplib.SMTP(smtp_server, port)
            server.starttls()
            server.login(sender_email, "PASSWORD")
            text = msg.as_string()
            server.sendmail(sender_email, recipient, text)
            server.quit()
            print(f"Email sent to {recipient}")
        except Exception as e:
            print(f"Failed to send email to {recipient}: {e}")

if __name__ == "__main__":
    severity = sys.argv[1]
    description = sys.argv[2] 
    eta = sys.argv[3]
    send_crisis_email(severity, description, eta)
```
