## 🎯 Objetivos de Capacitación

### Objetivo General
Capacitar a todos los usuarios del sistema InmoTech en el uso efectivo del nuevo módulo de gestión de ofertas y negociación, asegurando una adopción exitosa y aprovechamiento completo de las funcionalidades.

### Objetivos Específicos por Rol
```yaml
Compradores (Buyers):
  - Crear ofertas completas y competitivas
  - Entender el proceso de negociación
  - Gestionar múltiples ofertas activas
  - Utilizar documentos y condiciones especiales

Vendedores (Sellers):
  - Evaluar y responder ofertas eficientemente  
  - Hacer contrapropuestas estratégicas
  - Gestionar múltiples ofertas simultáneas
  - Optimizar tiempos de respuesta

Agentes Inmobiliarios:
  - Asesorar clientes en proceso de ofertas
  - Gestionar ofertas de múltiples propiedades
  - Utilizar analíticas para optimizar estrategias
  - Coordinar negociaciones complejas

Administradores:
  - Monitorear actividad del sistema
  - Gestionar configuraciones avanzadas
  - Generar reportes de actividad
  - Resolver incidencias de usuarios
```

## 📚 Estructura del Programa de Capacitación

### Módulo 1: Introducción al Sistema de Ofertas (1 hora)

#### 🎯 Objetivos del Módulo
- Entender el propósito y beneficios del sistema
- Conocer la terminología y conceptos clave  
- Familiarizarse con la interfaz general

#### 📋 Contenido Temático
```yaml
1.1 ¿Qué son las Ofertas Digitales? (15 minutos)
    - Concepto de oferta inmobiliaria digital
    - Ventajas vs proceso tradicional
    - Casos de uso comunes
    - Estadísticas de la industria

1.2 Roles y Permisos (15 minutos)
    - Qué puede hacer cada tipo de usuario
    - Flujo de una negociación típica
    - Responsabilidades por rol
    - Escalamiento y soporte

1.3 Navegación Básica (20 minutos)
    - Ubicación del módulo en el sistema
    - Panel principal de ofertas
    - Menús y navegación
    - Estados y notificaciones

1.4 Conceptos Clave (10 minutos)
    - Estados de oferta (pendiente, aceptada, etc.)
    - Términos de pago y condiciones
    - Fechas importantes (vencimiento, cierre)
    - Documentos y adjuntos
```

#### 🎓 Actividades Prácticas
- **Demo guiada:** Recorrido por la interfaz (10 min)
- **Ejercicio:** Identificar elementos en panel (5 min)

#### ✅ Criterios de Evaluación
- [ ] Identifica correctamente los elementos del panel
- [ ] Explica los diferentes estados de una oferta
- [ ] Navega sin ayuda por las secciones principales

### Módulo 2: Creando y Enviando Ofertas (1.5 horas)

#### 🎯 Objetivos del Módulo
- Crear ofertas completas y profesionales
- Configurar términos de pago apropiados
- Adjuntar documentos necesarios
- Enviar ofertas exitosamente

#### 📋 Contenido Temático
```yaml
2.1 Iniciando una Oferta (20 minutos)
    - Desde página de propiedad
    - Información pre-poblada
    - Verificación de disponibilidad
    - Requisitos mínimos

2.2 Configuración Financiera (25 minutos)
    - Determinación del monto de oferta
    - Términos de pago (contado, financiamiento, mixto)
    - Porcentajes de financiamiento
    - Cálculo de pagos iniciales

2.3 Condiciones y Términos (20 minutos)
    - Condiciones estándar vs personalizadas
    - Fechas de vencimiento estratégicas
    - Fechas de cierre realistas
    - Contingencias comunes

2.4 Documentación de Respaldo (15 minutos)
    - Tipos de documentos requeridos
    - Proceso de upload
    - Verificación de archivos
    - Privacidad y seguridad

2.5 Revisión y Envío (10 minutos)
    - Checklist pre-envío
    - Confirmación final
    - Qué sucede después del envío
    - Modificaciones post-envío
```

#### 🎓 Actividades Prácticas
- **Laboratorio:** Crear oferta completa paso a paso (30 min)
- **Simulación:** Diferentes escenarios de pago (15 min)
- **Práctica:** Upload y gestión de documentos (10 min)

#### ✅ Criterios de Evaluación
- [ ] Crea oferta con información completa y válida
- [ ] Configura términos de pago apropiados
- [ ] Adjunta documentos correctamente
- [ ] Envía oferta sin errores

3.4 Vencimientos y Reactivación (20 minutos)
    - Alertas de vencimiento

### Módulo 4: Respondiendo a Ofertas (Vendedores) (1.5 horas)

#### 🎯 Objetivos del Módulo
- Evaluar ofertas recibidas profesionalmente
- Tomar decisiones informadas (aceptar/rechazar/contraproponer)
- Gestionar timing y expectativas
- Maximizar valor en negociaciones

#### 📋 Contenido Temático
```yaml
4.1 Evaluación de Ofertas (25 minutos)
    - Análisis financiero de ofertas
    - Evaluación de términos de pago
    - Verificación de documentación
    - Comparación entre múltiples ofertas

4.2 Estrategias de Respuesta (30 minutos)
    - Cuándo aceptar directamente
    - Cuándo y cómo hacer contrapropuestas
    - Cuándo rechazar (y cómo comunicarlo)
    - Gestión de timing estratégico

4.3 Creando Contrapropuestas (20 minutos)
    - Ajuste de montos y términos
    - Modificación de fechas
    - Nuevas condiciones o contingencias
    - Comunicación de cambios

4.4 Comunicación Efectiva (15 minutos)
    - Mensajes profesionales
    - Transparencia y honestidad
    - Manejo de expectativas
    - Construcción de relaciones
```

#### 🎓 Actividades Prácticas
- **Simulación:** Evaluación de 3 ofertas reales (30 min)
- **Role-play:** Negociación con contrapropuestas (20 min)
- **Workshop:** Redacción de respuestas profesionales (15 min)

#### ✅ Criterios de Evaluación
- [ ] Evalúa ofertas considerando todos los factores relevantes
- [ ] Crea contrapropuestas estratégicas y bien fundamentadas
- [ ] Comunica decisiones de manera profesional y clara

## 🎓 Metodología de Capacitación

### Modalidades de Entrenamiento

#### 🏫 Presencial (40% del tiempo)
```yaml
Ventajas:
  - Interacción directa con instructor
  - Práctica hands-on inmediata
  - Resolución de dudas en tiempo real
  - Network entre participantes

Formato:
  - Sesiones de 2-3 horas máximo
  - Grupos pequeños (6-8 personas)
  - Mix de teoría y práctica
  - Role-playing y simulaciones

Recursos:
  - Aula con computadores
  - Proyector y sistema audio
  - Ambiente de pruebas dedicado
  - Material impreso de apoyo
```

#### 💻 Virtual Sincrónico (30% del tiempo)
```yaml
Ventajas:
  - Flexibilidad geográfica
  - Grabación para revisión posterior
  - Costo-efectivo
  - Participación de expertos remotos

Formato:
  - Webinars interactivos
  - Demos en vivo
  - Q&A sessions
  - Breakout rooms para práctica

Herramientas:
  - Zoom/Teams con screen sharing
  - Interactive polls y quizzes
  - Chat para Q&A
  - Sandbox environment access
```

#### 📚 Auto-estudio (30% del tiempo)
```yaml
Ventajas:
  - Ritmo personalizado
  - Disponibilidad 24/7
  - Revisión repetida
  - Costo mínimo de delivery

Recursos:
  - Video tutorials paso a paso
  - Interactive e-learning modules
  - PDF guides y quick references
  - Knowledge base con FAQs

Plataforma:
  - LMS (Learning Management System)
  - Seguimiento del progreso
  - Certificación digital
  - Community forums
```
