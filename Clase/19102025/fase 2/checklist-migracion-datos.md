# Checklist de Migración de Datos

- [ ] Definir estrategia de migración (manual, automatizada, híbrida)
- [ ] Identificar fuentes y destino de datos
- [ ] Realizar limpieza de datos
- [ ] Validar integridad y calidad de datos
- [ ] Ejecutar migración
- [ ] Verificar resultados y corregir errores
- [ ] Documentar incidencias y soluciones
